# Web UI

Локальная панель для обслуживания колонок, LLM-роутера и ключей.
Работает на том же хосте, что и скрипты проекта.

## Что умеет

- показывает профили колонок из `local/speakers/` с маскированными MAC и
  device ID;
- запускает разрешённые действия: статус Bridge, проверку LLM, запись
  ключа, routing, установку Bridge, подготовку root/SSH;
- показывает лог задания в реальном времени;
- читает и сохраняет `secrets/router-routes.json`, проверяя его через
  штатный `load_config()` роутера;
- генерирует и ротирует промежуточные токены, записывает upstream-ключи;
- ведёт журнал действий в `webui-state/audit.jsonl`.

Чего панель **не** делает:

- не выполняет сброс колонки и первичную привязку в приложении
  «Дом с Алисой» — это ручные шаги из `docs/03-runbook.md`;
- не показывает существующие значения ключей (только «есть/нет»);
- не принимает произвольные shell-команды: только белый список.

## Установка

```bash
python3 -m pip install -r requirements-webui.txt
python3 -m webui.admin set-password
```

Пароль хранится как scrypt-хеш в `secrets/webui-admin.hash` с режимом
`0600`. Сессионный ключ создаётся автоматически в
`secrets/webui-session.key`.

## Запуск

```bash
make webui
```

По умолчанию панель слушает `http://127.0.0.1:8080`.

Доступ с других устройств локальной сети:

```bash
WEBUI_HOST=0.0.0.0 WEBUI_PORT=8080 python3 -m webui
```

Не публикуйте порт в интернет и не пробрасывайте его на роутере. Если
нужен HTTPS, ставьте панель за локальный nginx и не открывайте порт
наружу.

## systemd

```bash
sudo cp deploy/webui.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now webui
```

Перед копированием замените `User`, `WorkingDirectory` и путь в
`ExecStart` на свои.

## Действия

Колонка:

| Действие | Что делает |
|---|---|
| `status` | версия Bridge, процесс, `check-backends`, место на `/data` |
| `check` | тестовый запрос к LLM через роутер |
| `key` | записывает `LLM_*` из профиля в `runtime.env` колонки |
| `routing` | применяет политику маршрутизации Bridge |
| `bridge` | ставит/обновляет Quasar Bridge |
| `root` | настраивает SSH/Dropbear и отключает OTA |

Хост:

| Действие | Что делает |
|---|---|
| `firmware` | скачивает прошивку |
| `router-start` | запускает контейнер роутера |
| `router-stop` | останавливает контейнер |
| `router-restart` | перезапускает контейнер |

Задания на одну колонку выполняются строго по очереди. Логи:
`webui-state/jobs/<id>.log`.

## Ключи

- Промежуточный токен: `secrets/router-token-<route>`.
- FLAI: `secrets/flai-token-<route>`.
- Orca: `secrets/orca-token-<route>`.

Новый токен показывается один раз после ротации. Сразу после этого
запишите его в колонку:

```bash
SPEAKER_ENV=local/speakers/<name>.env ./scripts/set-speaker-key.sh
```

## Аудит и отзыв доступа

- `webui-state/audit.jsonl` — последние действия; старые записи можно
  удалять вручную.
- Сменить пароль: `python3 -m webui.admin set-password`.
- Отозвать все сессии: удалить `secrets/webui-session.key` и
  перезапустить панель.
- Полностью отключить вход: удалить `secrets/webui-admin.hash` — вход
  вернёт `503`, пока пароль не задан снова.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `WEBUI_HOST` | `127.0.0.1` | адрес прослушивания |
| `WEBUI_PORT` | `8080` | порт |
| `WEBUI_ROOT` | текущий каталог | корень проекта |
| `WEBUI_JOB_TIMEOUT` | `600` | таймаут задания, секунд |
| `WEBUI_MAX_WORKERS` | `2` | одновременных заданий |

## Диагностика

- Панель не стартует: проверьте, что установлен Flask и задан пароль.
- `503` на форме входа: нет `secrets/webui-admin.hash`.
- Задание сразу `failed`: откройте его лог; чаще всего не найден профиль,
  SSH-ключ или контейнер роутера.
- Health роутера `unavailable`: контейнер `llm-router` не запущен или
  слушает другой порт.
